# Task List (maintained fork)

A mod for Farming Simulator 25 for managing tasks and related workflows.

This repository is a fork of [Ozz-Modding/FS25_TaskList](https://github.com/Ozz-Modding/FS25_TaskList).

## Why this fork?

The upstream mod had a bug with **recurring tasks**: after completion they could stop reappearing on the scheduled period (especially with every-N-months recurrence, where the next period was not wrapped correctly into the 1–12 month range).

A pull request with the fix was opened against the original repository ([#48](https://github.com/Ozz-Modding/FS25_TaskList/pull/48)) and left unanswered for about half a year. This fork includes that fix and follow-up work, and is currently the more up-to-date codebase for active use and further development.
